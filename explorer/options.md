# Options

Options -std, -Wall, -Wextra, -Wpedantic, -O0 and -o

[06.02](../projects/examples/source/06.02.cpp) : Preprocessing. Preprocessor Directives. Using Libraries. Directive #include. Object and Function Macros. Directives #define and #undef. Operators \, ## and #. Side Effects. Runtime Assertions. Macro assert. Conditional Compilation. Directives #if, #else and #endif. Suppressing Compiler Warnings. Directive #pragma. Options -E and -DNDEBUG

[06.06](../projects/examples/source/06.06.hpp) : Precompiled Header Files. Option -c

[06.08](../projects/examples/source/06.08.cpp) : Internal and External Linking. Multiply Defined and Unresolved External Symbols. Global, Local, Weak and Unique Symbols. Tools readelf and grep. Link-Time Optimization (LTO). Option -flto

[06.13](../projects/examples/source/06.13.cxx) : Modules. Module Interface Units. Declaration module. Global Module Fragments. Exports and Imports. Declarations export and import. Standard Library Modules. Single, Group and Namespace Exports. Private Module Fragments. Options -fmodules-ts and -xc++-system-header

[07.14](../projects/examples/source/07.14.cpp) : Debugging. Options -g and -ggdb. GNU DeBugger (GDB). Tool gdb. Commands run, continue, next, step, break, print and backtrace

[07.15](../projects/examples/source/07.15.cpp) : Debugging. Address Sanitizers. Heap-Buffer-Overflow Errors. Memory Leaks. Use-After-Free Errors. Option -fsanitize. Tool valgrind

[07.18](../projects/examples/source/07.18.cpp) : Profiling. Algorithm std::ranges::iota. Functions std::pow, std::sin and std::cos. Profile-Guided Optimization (PGO). Options -fprofile-generate and -fprofile-use. Tool time

[07.23](../projects/examples/source/07.23.cpp) : Microbenchmarking. Library Google.Benchmark. Algorithm std::ranges::lower_bound. Option -O3. Frequency Scaling. Address Space Layout Randomization (ASLR). Task Affinities. Task Scheduling Algorithms. Preemptive and Cooperative Multitasking. First In First Out (FIFO) Algorithm. Tools cpupower, uname, setarch, taskset and chrt
